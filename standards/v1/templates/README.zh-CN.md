# web-sdk-<model>

[English](README.en.md)

浏览器端 `<model>` SDK，默认在本地运行。

## 安装

```bash
pnpm add web-sdk-<model>
```

## 在线 Demo

- [打开在线 Demo](https://owner.github.io/web-sdk-<model>/)
- [GitHub](https://github.com/owner/web-sdk-<model>)

Demo 默认中文，支持中英文切换，并显示模型信息、请求/实际后端、执行模式、
下载/缓存/加载/推理耗时和缓存清理入口。

## 验证

```bash
pnpm verify
```

模型来源、许可证、精度、大小和 SHA-256 见 `sdk-manifest.yaml`。
