# web-sdk-<model>

[中文（默认）](README.md)

Browser-first `<model>` SDK with local inference by default.

## Install

```bash
pnpm add web-sdk-<model>
```

## Live Demo

- [Open Demo](https://owner.github.io/web-sdk-<model>/)
- [GitHub](https://github.com/owner/web-sdk-<model>)

The Demo starts in Chinese, provides an in-page language toggle, and reports
model metadata, requested/actual backend, execution mode, download/cache/load/
inference timings, and cache cleanup.

See [English quick start](docs/en/quick-start.md), [API](docs/en/api.md), and
the [Chinese docs](docs/zh-CN/quick-start.md).
