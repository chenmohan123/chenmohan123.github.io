## 集成中修正

- API 新代码段补齐公开导入，通过 TypeScript 片段编译。
- 移除新加的固定源码字符串镜像测试，保留既有示例契约登记；模型选择、摘要、取消和真实推理由浏览器行为证据验证。最终示例契约为 12 项通过；实现者报告的 13 项是集成前状态。
- API 与排障说明改为：缺少 Content-Length 时使用清单声明的总字节数，避免与下载器行为冲突。
- 澄清 Demo 默认 PicoDet，而每个模型清单分别默认 ModelScope/FP32；表格声明模型大小单位为字节。
- 新示例控制样式使用标准 UI token 的颜色、圆角和焦点值；为 hidden 画布显式设置隐藏规则，避免普通 canvas 样式覆盖浏览器 hidden 状态。
