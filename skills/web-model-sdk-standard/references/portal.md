# Portal Workflow

Read `standards/v1/portal-contract.md`. Portal changes update registry records,
categories, comparisons, links, and optional checker reports. Single-SDK pages
link to GitHub, npm, and the independent live Demo; they do not import or copy
the SDK runtime.

Combination recipes may describe multi-SDK value. Start a Workflow/Playground
implementation only after at least two SDKs have compatible public contracts,
an explicit input/output mapping, and a documented composition use case. Keep
UI tokens and state labels aligned with the standalone Demos while allowing a
denser catalog layout.
